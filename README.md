# Ray - Your AI Interview Coach

Ray is a smart interview practice platform that simulates real job interviews. It uses advanced AI to conduct voice-based interviews, listen to your answers, and give you improved feedback to help you land your dream job.

## How it works
1. **Choose your role:** Select the job position you want to practice for.
2. **Speak naturally:** Answer questions just like in a real interview.
3. **Get Feedback:** Receive detailed analysis on your answers and tips to improve.

## Tech Stack
We use the latest tech to ensure a smooth experience:
- **Frontend:** Next.js 16, React 19, Tailwind CSS 4
- **AI & Voice:** Vapi AI (Voice), Google AI SDK
- **Backend & Database:** Firebase
- **Language:** TypeScript

## Setup Instructions

1. **Update environment variables**
   Create a `.env.local` file using `.env.example` as a template.

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000) in your browser.
